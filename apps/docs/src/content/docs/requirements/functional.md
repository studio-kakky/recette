MVP は「登録 → 整理 → 見つける → 買い物」の一連の流れが最小限成立することをゴールとする。

## 1. 認証

- Google などの **OAuth ログインのみ**（パスワード管理はしない）
- 初回ログインでアカウント自動作成
- ログアウト

## 2. レシピ管理

### レシピの種類

1 つの「レシピ」は次のいずれの形でも成立する（全部入りでも、URL だけでもよい）。

- **自作レシピ**: タイトル + 材料 + 手順 + メモ + 写真
- **ブックマーク型レシピ**: URL + タイトル + タグ + メモ（本文は元サイトで見る）
- **写真型レシピ**: 本のページやスクショの画像 + タイトル + タグ

### フィールド

| フィールド | 必須 | 備考 |
| --- | --- | --- |
| タイトル | ✅ | |
| 材料 | - | 「材料名 + 分量」の行リスト（例: `豚肉 / 300g`）。行の追加・削除・並べ替え |
| 手順 | - | 番号付きの行リスト、またはフリーテキスト |
| メモ | - | フリーテキスト（コツ・アレンジなど） |
| 写真 | - | 複数枚添付可。レシピの参照用（本のページ・スクショ・完成イメージなど）。実際に作ったときの写真は「作った記録」に登録する |
| URL | - | 参照元リンク。取得は行わず手入力（OGP 取得は将来） |
| タグ | - | 複数付与可 |

### 操作

- 作成 / 閲覧 / 編集 / 削除
- 一覧表示（更新日時順）

## 3. 作った記録

レシピの参照用写真とは別に、**実際に作ったときの写真を 1 回分の記録として残せる**。写真を残すことが目的の機能なので、写真は必須。

| フィールド | 必須 | 備考 |
| --- | --- | --- |
| 写真 | ✅ | 1 枚以上、複数枚可 |
| 作った日 | ✅ | デフォルトは当日。過去日も選べる |
| メモ | - | 一言（例: 砂糖を減らした / 家族に好評） |

- レシピ詳細に作った記録が新しい順で並ぶ（写真 + 日付 + メモ）
- 記録の追加・編集・削除
- レシピ詳細・一覧で**作った回数**が見える（記録数のカウント）

## 4. 整理・検索

- **タグ**: ユーザーが自由に作成・付与（例: 和食 / 作り置き / 15分以内）。タグで一覧を絞り込み
- **キーワード検索**: タイトル・材料名・メモを横断して部分一致検索
- タグ絞り込みとキーワード検索は併用できる

## 5. 買い物リスト

レシピとは独立した 1 本のリスト（ユーザーごと）。

- 項目の追加（フリーテキスト。例: `牛乳`、`豚肉 300g`）
- **レシピ詳細から材料を選んで買い物リストに追加**できる
- チェック ON/OFF（買った / まだ）
- チェック済み項目の一括削除
- スマホの片手操作でチェックしやすい UI であること

## 6. 画面一覧

| 画面 | 主な内容 |
| --- | --- |
| ログイン | OAuth ボタンのみ |
| レシピ一覧（ホーム） | レシピカードのリスト（作った回数表示）、タグ絞り込み、検索、新規作成ボタン |
| レシピ詳細 | 全フィールド表示、作った記録の一覧・追加、材料→買い物リスト追加、編集・削除 |
| レシピ作成・編集 | フォーム。材料・手順の行編集、写真アップロード、タグ付け |
| 買い物リスト | チェックリスト、追加、チェック済み一括削除 |

## MVP でやらないこと

以下は意図的にスコープ外とする（詳細は [ロードマップ](/requirements/roadmap/)）。

- 写真からの AI テキスト起こし（OCR）
- URL からのタイトル・サムネイル自動取得（OGP）、本文抽出
- 複数レシピの材料を合算した買い物リスト生成
- 献立計画（カレンダー）
- お気に入り・評価、固定カテゴリ
- 人数分換算
- レシピの共有・公開
- オフライン対応（PWA）
