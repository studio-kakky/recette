MVP を使ってみて困った順に着手する。以下は現時点の仮説的な優先順位。

## Phase 2 — 登録をもっと楽に

- **URL の OGP 自動取得**: URL を貼るとタイトル・サムネイルが自動で入る
- **写真の AI テキスト起こし**: 本のページやスクショから材料・手順を抽出してフォームに反映
- タグのサジェスト（既存タグの補完）

## Phase 3 — 使う場面を広げる

- **PWA 化**: ホーム画面追加 + 買い物リストのオフライン対応（店内の電波対策）
- お気に入り・「また作りたい度」の記録と並べ替え
- 作った記録のタイムライン表示（レシピ横断で「最近作ったもの」を時系列に眺める）
- 複数レシピを選んで材料をまとめて買い物リストへ

## Phase 4 — 計画する

- 献立計画（週カレンダーにレシピを割り当て → 買い物リスト生成）
- 人数分換算（amount の構造化が前提になるため大きめの変更）

## 検討中・保留

| アイデア | 保留理由 |
| --- | --- |
| レシピの URL 共有（特定レシピのみ公開） | 「共有はしない」方針。要望が出たら再検討 |
| レシピ本文の自動抽出（スクレイピング） | 実装・法律・対象サイト対応のコストが高い。OGP + 元サイト閲覧で十分か見極める |
| 固定カテゴリ（主菜/副菜など） | タグで代替できる想定。タグ運用が破綻したら検討 |
