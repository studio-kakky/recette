## プロダクト名

**Recette**（ルセット）— 自分用のレシピを管理するアプリ。

## 背景・課題

- 自分のレシピ（オリジナル・覚え書き・見つけたもの）が、メモアプリ・スクショ・ブックマークなどに散らばっていて見返せない
- 買い物中に「あのレシピ、何が要るんだっけ」をすぐ確認できない

## 目的

散らばったレシピを 1 か所にストックし、**記録・整理**と**買い物時の確認**をスマホでスムーズにできるようにする。

## コンセプト

> 入り口は雑でいい。あとから見つかればいい。

- 手入力・写真・URL、どんな形でもとりあえず放り込める
- タグとキーワード検索で必要なときに見つかる
- 買い物リストで「今日買うもの」に落とし込める

## ユーザー

- 複数ユーザーが利用するが、**共有機能はない**
- 各ユーザーは自分のレシピ・買い物リストだけを閲覧・編集できる（完全にユーザーごとに独立したデータ空間）

## 利用シーン

| シーン | 行動 |
| --- | --- |
| レシピを見つけた・思いついた | スマホや PC からサッと登録する（手入力 / 写真 / URL） |
| 献立が決まった | レシピの材料を買い物リストに追加する |
| スーパーで買い物中 | スマホで買い物リストを見ながらチェックしていく |
| 作ったあと | 完成した料理の写真を「作った記録」として残す |
| 何を作るか探す | タグやキーワードで自分のストックから探す |
